# VetroLog

**VetroLog** is an open-source, high-performance desktop SQLite database inspector engineered specifically for mobile developers. It delivers zero-SDK-code database debugging across **Flutter**, **Android Native (Kotlin/Java)**, and **React Native** via Android Debug Bridge (ADB), paired with live WAL synchronization, a visual query planner, and natural language AI query assistance.

Official Repository: [github.com/frozenlabx/vetrolog](https://github.com/frozenlabx/vetrolog)

## ⚡ Why Mobile Developers Choose VetroLog

- **Official VS Code Extension**: Inspect mobile SQLite databases, remote database engines (Postgres, MySQL, MariaDB, MSSQL, Redis), and double-click workspace `.db` files directly inside your editor.
- **Zero SDK Boilerplate**: No SDK installation or network listeners required. VetroLog securely accesses app databases directly via Android Debug Bridge (`run-as`).
- **Real-Time WAL Auto-Sync**: Monitors SQLite Write-Ahead Logging (`-wal`) and Shared Memory (`-shm`) files live. Table data updates instantaneously on desktop when writes occur.
- **Intelligent SQL Console**: Multi-tab query editor with dot-notation column autocomplete, schema awareness, and execution timing.
- **Visual Query Plan & 60 FPS Profiler**: Evaluates `EXPLAIN QUERY PLAN` visually with high-cost table scan alerts, and benchmarks latency against the mobile 16.6ms UI frame budget.
- **Natural Language AI**: Translates plain English into optimized SQLite queries using Google Gemini 2.5 Flash, OpenAI, or local Ollama models.
- **Multi-Platform & Web Mode**: Native desktop application on macOS, Windows, and Linux, plus standalone headless Web Server mode (`./vetrolog --web`).
