# VetroLog

**VetroLog** is an open-source structured logging and observability library developed under the FrozenLab initiative. It is engineered to provide developers with clear, low-overhead contextual logging without introducing cumbersome dependency trees.

Official Repository: [github.com/frozenlabx/vetrolog](https://github.com/frozenlabx/vetrolog)

## Core Architectural Objectives

VetroLog is designed around three fundamental engineering principles:

1. **Deterministic Structured Output**: Machine-readable JSON formatting for production environments paired with human-readable colored streams for local terminal sessions.
2. **Predictable Low Overhead**: Careful allocation profiling to ensure logging remains non-blocking even under demanding I/O loads.
3. **Ergonomic Context Propagation**: First-class support for child loggers, contextual metadata attachment, and redaction hooks.
