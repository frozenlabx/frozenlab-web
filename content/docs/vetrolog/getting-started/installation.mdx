### macOS

    ### 🍺 Method A: Homebrew Cask (Recommended)

    Install VetroLog directly using the official tap:

    ```bash
    brew install tanvirul-swe/tap/vetrolog
    ```

    Or add the tap first and install:
    ```bash
    brew tap tanvirul-swe/tap
    brew install --cask vetrolog
    ```

    ---

    ### 📦 Method B: Direct DMG Download


      [Download macOS DMG (Universal)
      ](https://github.com/Tanvirul-swe/vetrolog/releases/latest/download/VetroLog-macOS-Universal.dmg)
      [Download .zip Archive
      ](https://github.com/Tanvirul-swe/vetrolog/releases/latest/download/VetroLog-macOS-Universal.zip)



      `Apple Silicon (M1/M2/M3/M4)`
      `Intel Mac (x86_64)`
      `Universal 64-bit`


    1. **Download the installer**: Click the **Download macOS DMG** button above.
    2. **Mount the disk image**: Double-click the downloaded `VetroLog-macOS-Universal.dmg` file.
    3. **Install to Applications**: Drag the **VetroLog.app** icon into your **Applications** folder.
    4. **Launch VetroLog**: Open VetroLog from your Applications folder, Launchpad, or Spotlight (`Cmd + Space` &rarr; `VetroLog`).

    > [!WARNING] macOS Gatekeeper First-Launch Prompt
    > Because VetroLog is open-source and distributed directly without Apple's paid Developer notarization program, macOS may display a Gatekeeper dialog (*"VetroLog cannot be opened because the developer cannot be verified"*).
    >
    > **To open with 1 click:**
    > - Right-click (or Control-click) `VetroLog.app` in `/Applications` and select **Open**, then click **Open** in the dialog.
    > - Or run this command in your Terminal:
    >   ```bash
    >   xattr -d com.apple.quarantine /Applications/VetroLog.app
    >   ```

### Linux

    ### 🛍️ Method A: Snap Store / Ubuntu App Center

    Available on Ubuntu, Debian, Fedora, and openSUSE:

    ```bash
    sudo snap install vetrolog
    ```

    ---

    ### 🏹 Method B: Arch User Repository (AUR)

    For Arch Linux, Manjaro, and EndeavourOS:

    ```bash
    yay -S vetrolog-bin
    ```

    ---

    ### 📦 Method C: Debian / Ubuntu Package (`.deb`)

      [Download Debian / Ubuntu (.deb)
      ](https://github.com/Tanvirul-swe/vetrolog/releases/latest/download/VetroLog-Linux-amd64.deb)
      [Download Tarball (.tar.gz)
      ](https://github.com/Tanvirul-swe/vetrolog/releases/latest/download/VetroLog-Linux-x64.tar.gz)

    1. **Download Package**: Click **Download Debian / Ubuntu (.deb)** above.
    2. **Install via Terminal**:
       ```bash
       sudo dpkg -i VetroLog-Linux-amd64.deb
       # If any dependencies are missing, auto-resolve with:
       sudo apt-get install -f
       ```
    3. **Launch**: Open from your application drawer or run `vetrolog` in your terminal.

    ---

    ### 📦 Method D: Standalone Tarball (All Linux Distributions)
    1. Download and extract `VetroLog-Linux-x64.tar.gz`:
       ```bash
       tar -xvf VetroLog-Linux-x64.tar.gz
       cd VetroLog-Linux-x64
       ./vetrolog
       ```

    > [!NOTE] System Dependencies for Linux
    > VetroLog utilizes the native GTK3 and WebKit engine. Ensure your distribution has the runtime libraries:
    > - **Debian / Ubuntu**: `sudo apt install libgtk-3-0 libwebkit2gtk-4.0-37` (or `libwebkit2gtk-4.1-0`)
    > - **Fedora**: `sudo dnf install gtk3 webkit2gtk4.1`
    - **Arch**: `sudo pacman -S gtk3 webkit2gtk-4.1`
    :::

## 🌐 Headless Web Server Mode (Docker & Remote Machines)

If you are developing inside a headless Linux VM, remote server, or Docker container where no desktop display is available, VetroLog includes a built-in headless web server mode:

```bash
# Launch VetroLog as a local web server (default: http://localhost:8787)
./vetrolog --web

# Or specify a custom port
./vetrolog --web --port 9090

# Or prevent auto-opening the browser on startup
./vetrolog --web --no-browser
```

Simply open **`http://localhost:8787`** in your favorite browser (Google Chrome, Safari, Firefox, Edge).

## 🛠️ Building from Source

If you want to contribute or build VetroLog from the source code:

### Prerequisites

- **Go 1.22+**: [golang.org](https://go.dev/)
- **Node.js 20+** & **npm**: [nodejs.org](https://nodejs.org/)
- **Wails v2 CLI**:
  ```bash
  go install github.com/wailsapp/wails/v2/cmd/wails@latest
  ```

### Build Instructions

```bash
# 1. Clone the repository
git clone https://github.com/Tanvirul-swe/vetrolog.git
cd vetrolog

# 2. Install frontend dependencies
cd frontend && npm install && cd ..

# 3. Run in live hot-reload development mode
wails dev

# 4. Or compile a production release binary
wails build
```

The compiled native executable will be located in the `build/bin/` folder.
