# VetroLog Guides

Explore guided implementation examples for integrating VetroLog into your stack.

## Guides Index

- **HTTP Request Correlation**: Propagating request IDs across asynchronous call trees using Node.js `AsyncLocalStorage`.
- **Cloud Log Collectors**: Forwarding structured JSON output directly to cloud collectors such as Datadog, AWS CloudWatch, and Grafana Loki.
- **Custom Sinks**: Writing custom writable streams to pipe logs over UDP or persistent Unix sockets.
