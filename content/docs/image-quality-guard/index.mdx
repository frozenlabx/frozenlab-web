# Image Quality Guard

**Image Quality Guard** is an open-source asset verification utility developed by FrozenLab to enforce deterministic quality, dimension, and compression boundaries across frontend repositories and continuous integration pipelines.

Official Repository: [github.com/frozenlabx/image_quality_guard](https://github.com/frozenlabx/image_quality_guard)

## Why Image Quality Guard?

Uncompressed or oversized image assets frequently introduce severe performance regressions in production web applications:

- Huge payload sizes degrade Core Web Vitals (specifically LCP).
- Unintended resolution spikes consume excessive client memory.
- Inconsistent format adoption (e.g. shipping uncompressed PNGs instead of WebP/AVIF).

Image Quality Guard acts as an automated safety net to catch these issues in pull requests before assets reach end users.
